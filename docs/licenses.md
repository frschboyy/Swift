# Licenses

The Python table is generated by `uv run pip-licenses --format=markdown --with-urls --order=license`. Regenerate it whenever `uv.lock` changes. Models and voices are tracked by hand in the second table.

**Audience:** personal use (ADR-000). Before any distribution, the §15 license review gate must pass.
